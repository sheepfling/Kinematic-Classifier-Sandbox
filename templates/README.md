# Templates

This directory holds small starter files for new studies and manifests.

Current templates:

- `study_candidate.yaml`
- `corpus_objective.yaml`
- `class_manifest.csv`
- `feature_manifest.csv`
- `prior_manifest.csv`

Use these when bootstrapping a new study or corpus definition so the config
shape stays consistent with the rest of the repo.

Templates are source inputs, not generated artifacts.
