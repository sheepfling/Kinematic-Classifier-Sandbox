# Presentation Blend Lane

## Purpose

The presentation lane exports run-backed methodology evidence for a specific audience. It should consume existing run artifacts rather than define new study logic.

Current export profiles include methodology proof decks, appendix decks, decision cards, lane proof matrices, and claim-boundary packets.

## Outputs

- `artifacts/presentation_hero_charts_v4/main_deck.pptx`
- `artifacts/presentation_hero_charts_v4/appendix_deck.pptx`
- `artifacts/presentation_hero_charts_v4/decision_card.md`
- `artifacts/presentation_hero_charts_v4/lane_proof_matrix.md`

## Claim Boundary

A presentation packet is an evidence export, not a separate code path. Audience-specific language must not change the underlying study decision.
