# Three-Epic Story

The Anduril/C2 presentation profile is organized as three chapters of one methodology system:

1. Static Admissibility: can the study be decided?
2. Classifier / Filter Ladder: what evidence builder is sufficient?
3. Corpus Evaluation and Advanced Exploration: can the workbench discover valid hard cases?

The epics share one `StudySpec`, one evidence/posterior contract, and one `DecisionCard`. Presentation packets export the same artifacts for a specific audience; they do not create a separate methodology path.
