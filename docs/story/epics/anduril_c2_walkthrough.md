# Anduril/C2 Walkthrough

The Anduril/C2 packet is an export profile over the three epic packets:

1. Static Admissibility: screen the study before compute.
2. Classifier / Filter Ladder: build posterior track evidence over time.
3. Corpus Evaluation and Advanced Exploration: find valid hard cases and escalation evidence.

The deck order is presentation-oriented: admissibility, evidence, exploration, then decision. Operationally, Corpus Explorer and the ladder can iterate through the same decision-card contract.
