- `artifacts/validation_packets/v7_anduril_c2_blend/`
- Epic 1: reusable static admissibility gate
- Epic 2: evidence-construction ladder
- Epic 3: corpus explorer / experimental-design engine

The legacy `artifacts/packets/anduril_c2_blend/` packet is still useful as the inherited hero-deck export, but the V7 packet is the better final thesis shape because it makes each epic a proof system with its own decision surface.

1. Static Admissibility: screen the study before compute.
2. Classifier / Filter Ladder: build posterior track evidence over time.
3. Corpus Evaluation and Advanced Exploration: find valid hard cases and escalation evidence.

The deck order is presentation-oriented: admissibility, evidence, exploration, then decision. Operationally, Corpus Explorer and the ladder can iterate through the same decision-card contract.
