\section{Static Admissibility}

Static admissibility is the first methodology gate. Given a feature set, class set, and prior regime, it asks whether the study candidate is meaningful enough to send to corpus search or classifier evaluation.

The output is not a leaderboard score. The output is a decision card: promote to Corpus Explorer, promote with warnings, revise the feature set, revise the class set, revise the prior regime, block due to leakage, or reject as not decisionable.
