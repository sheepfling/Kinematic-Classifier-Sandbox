# 1D Witness Suite

The 1D witness problems are small controlled studies that prove methodology layers before the framework is lifted to 3D. They are not the final deployment corpus.

| Witness | What it proves | Card |
| --- | --- | --- |
| pointwise_overlap | likelihoods, priors, posterior flips | [pointwise_overlap.md](pointwise_overlap.md) |
| windowed_outlier_extrema | raw versus robust feature behavior | [windowed_outlier_extrema.md](windowed_outlier_extrema.md) |
| sequential_history | history helps beyond pointwise evidence | [sequential_history.md](sequential_history.md) |
| kalman_endpoint_match | model-based dynamics evidence helps | [kalman_endpoint_match.md](kalman_endpoint_match.md) |
| transition_switching | transition logic is justified before IMM | [transition_switching.md](transition_switching.md) |
| generated_corpus_stress | Corpus Explorer can discover hard or fragile examples | [generated_corpus_stress.md](generated_corpus_stress.md) |

The matrix source is `artifacts/repo_story/witness_problem_matrix.csv`.
