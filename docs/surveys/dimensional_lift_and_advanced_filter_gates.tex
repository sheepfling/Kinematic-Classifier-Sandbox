\section{IMM As An Actual Algorithm Family}

The current repo now has an explicit IMM proof surface in
\texttt{advanced\_state\_inference.py}. That means IMM should no longer be
documented only as a gate label. It should be documented as a switching
linear-Gaussian algorithm whose justification is still evidence-gated.

For mode set \(\mathcal{M} = \{1,\dots,M\}\), let \(\mu_{k-1}^{(i)}\) be the
mode posterior after step \(k-1\), and let \(\Pi_{ij}\) be the transition
probability from mode \(i\) to mode \(j\). The predicted mode prior is
\begin{equation}
\bar{\mu}_{k}^{(j)}
=
\sum_{i \in \mathcal{M}}
\Pi_{ij}\mu_{k-1}^{(i)}.
\end{equation}
The mode-mixing weights are then
\begin{equation}
\omega_{ij}^{(k)}
=
\frac{\Pi_{ij}\mu_{k-1}^{(i)}}{\bar{\mu}_{k}^{(j)}}.
\end{equation}
These are the exact quantities emitted by the current implementation as the
predicted mode prior and \texttt{mode\_mixing} rows.

If each mode \(j\) carries state estimate \(x_{k-1|k-1}^{(j)}\) and covariance
\(P_{k-1|k-1}^{(j)}\), the mixed initial condition for target mode \(j\) is
\begin{align}
\bar{x}_{k-1|k-1}^{(j)}
&=
\sum_{i \in \mathcal{M}}
\omega_{ij}^{(k)} x_{k-1|k-1}^{(i)},
\\
\bar{P}_{k-1|k-1}^{(j)}
&=
\sum_{i \in \mathcal{M}}
\omega_{ij}^{(k)}
\Big(
P_{k-1|k-1}^{(i)}
+
\big(x_{k-1|k-1}^{(i)}-\bar{x}_{k-1|k-1}^{(j)}\big)
\big(x_{k-1|k-1}^{(i)}-\bar{x}_{k-1|k-1}^{(j)}\big)^\top
\Big).
\end{align}
This is the mathematical distinction between IMM and the simpler
transition-matrix accumulator: IMM mixes full latent-state distributions, not
only class probabilities.

Each mode then executes its own predict/update step. For mode \(j\),
\begin{align}
\hat{x}_{k|k-1}^{(j)}
&=
F_k^{(j)}\bar{x}_{k-1|k-1}^{(j)} + b_k^{(j)},
\\
\hat{P}_{k|k-1}^{(j)}
&=
F_k^{(j)}\bar{P}_{k-1|k-1}^{(j)}F_k^{(j)\top} + Q_k^{(j)},
\\
\nu_k^{(j)}
&=
z_k - H_k^{(j)}\hat{x}_{k|k-1}^{(j)},
\\
S_k^{(j)}
&=
H_k^{(j)}\hat{P}_{k|k-1}^{(j)}H_k^{(j)\top} + R_k^{(j)}.
\end{align}
The mode likelihood is
\begin{equation}
\Lambda_k^{(j)}
=
\mathcal{N}\!\big(\nu_k^{(j)}; 0, S_k^{(j)}\big),
\end{equation}
or in log form,
\begin{equation}
\ell_k^{(j)}
=
\log \bar{\mu}_k^{(j)} + \log \Lambda_k^{(j)}.
\end{equation}
The updated mode posterior is therefore
\begin{equation}
\mu_k^{(j)}
=
\frac{\Lambda_k^{(j)}\bar{\mu}_k^{(j)}}{\sum_{m \in \mathcal{M}} \Lambda_k^{(m)}\bar{\mu}_k^{(m)}}.
\end{equation}
This is exactly the current repo's switching-aware state-evidence recursion:
mode priors are mixed, each mode emits an innovation likelihood, and the
mode-posterior vector is normalized again after evidence.

The final combined state estimate is
\begin{align}
x_{k|k}
&=
\sum_{j \in \mathcal{M}} \mu_k^{(j)} x_{k|k}^{(j)},
\\
P_{k|k}
&=
\sum_{j \in \mathcal{M}} \mu_k^{(j)}
\Big(
P_{k|k}^{(j)}
+
\big(x_{k|k}^{(j)}-x_{k|k}\big)\big(x_{k|k}^{(j)}-x_{k|k}\big)^\top
\Big).
\end{align}
The current implementation also aggregates mode posteriors into class
posteriors by log-sum-exp over modes belonging to the same class, so the IMM
proof still fits the shared posterior/evidence contract used elsewhere in the
repo.

\section{PF As A Nonlinear / Non-Gaussian Algorithm Family}

Particle filtering is the next rung only when the evidence shows that a
Gaussian mode model is the wrong approximation. In that case the state is
represented by a weighted sample set
\begin{equation}
    \{x_k^{(i)}, w_k^{(i)}\}_{i=1}^{N_p},
    \qquad
    \sum_{i=1}^{N_p} w_k^{(i)} = 1.
\end{equation}
The general sequential-importance proposal is
\begin{equation}
    x_k^{(i)} \sim q(x_k \mid x_{0:k-1}^{(i)}, z_{1:k}),
\end{equation}
which yields the unnormalized importance weight
\begin{equation}
    \tilde{w}_k^{(i)}
    =
    w_{k-1}^{(i)}
    \frac{
        p(z_k \mid x_k^{(i)})\,p(x_k^{(i)} \mid x_{k-1}^{(i)})
    }{
        q(x_k^{(i)} \mid x_{0:k-1}^{(i)}, z_{1:k})
    }.
\end{equation}
This is the core PF identity missing from the simpler ladder: particles are not
weighted only by likelihood, but by likelihood corrected by the proposal-to-
prior ratio.

For a bootstrap particle filter, the proposal is the state dynamics itself:
\begin{equation}
    x_k^{(i)} \sim p(x_k \mid x_{k-1}^{(i)}).
\end{equation}
The proposal ratio then cancels, so the particle weight update reduces to
\begin{equation}
    \tilde{w}_k^{(i)}
    =
    w_{k-1}^{(i)}\,p(z_k \mid x_k^{(i)}),
\end{equation}
with normalization
\begin{equation}
    w_k^{(i)}
    =
    \frac{\tilde{w}_k^{(i)}}{\sum_{j=1}^{N_p}\tilde{w}_k^{(j)}}.
\end{equation}
The state estimate is the weighted mean
\begin{equation}
    \hat{x}_k
    =
    \sum_{i=1}^{N_p} w_k^{(i)} x_k^{(i)},
\end{equation}
and the particle-set effective sample size is
\begin{equation}
    N_{\text{eff}}
    =
    \frac{1}{\sum_{i=1}^{N_p} (w_k^{(i)})^2}.
\end{equation}
The code gates resampling when \(N_{\text{eff}}\) falls below a threshold
fraction of \(N_p\), because particle degeneracy is the failure mode that makes
PF numerically unusable even when the model is conceptually right.
If \(N_{\text{eff}} < \tau_{\text{resample}} N_p\), the intended resampling
step is
\begin{equation}
    \{x_k^{(i)}, w_k^{(i)}\}_{i=1}^{N_p}
    \mapsto
    \{\tilde{x}_k^{(i)}, 1/N_p\}_{i=1}^{N_p},
\end{equation}
where \(\tilde{x}_k^{(i)}\) are resampled particles drawn with probabilities
proportional to \(w_k^{(i)}\). Resampling is therefore not part of the
Bayesian model itself; it is the numerical stabilization step that prevents a
single particle from carrying almost all posterior mass.

To fit the repo's shared evidence contract, class evidence must still be
extracted from the particle cloud. The intended class-conditioned predictive
evidence is
\begin{equation}
    \hat{p}(z_k \mid c)
    \approx
    \sum_{i=1}^{N_p}
    w_{k-1}^{(i,c)} p(z_k \mid x_k^{(i,c)}, c),
\end{equation}
where the superscript \((i,c)\) denotes particles propagated under class or
mode hypothesis \(c\). The posterior update then reuses the same shared form,
\begin{equation}
    p_k(c)
    \propto
    \hat{p}(z_k \mid c)\,p_{k-1}(c).
\end{equation}
This is the key connection to the rest of the repo: PF is allowed only if it
can still emit evidence rows that the shared posterior and evaluation layers
know how to consume.

The particle filter becomes evidence-gated when the current ladder cannot
explain a witness with either:
\begin{itemize}[leftmargin=1.5em]
    \item strongly nonlinear dynamics,
    \item multimodal posteriors,
    \item non-Gaussian observation noise,
    \item censoring, clipping, or saturation that breaks innovation Gaussianity.
\end{itemize}
If those failure conditions are not present, PF is unnecessary complexity.

\section{PF Process Summary}

The intended PF recursion in repo terms is:
\begin{enumerate}[leftmargin=1.5em]
    \item propagate particles with either the dynamics prior or a proposal
    \(q(\cdot)\),
    \item evaluate observation likelihoods at the new measurement,
    \item update and normalize importance weights,
    \item aggregate particle evidence into class-conditioned predictive
    evidence \(\hat{p}(z_k \mid c)\),
    \item update class posteriors with the shared posterior contract,
    \item compute \(N_{\mathrm{eff}}\) and resample only if the cloud has
    become too degenerate,
    \item emit the standard evidence/posterior/diagnostic rows used everywhere
    else in the repo.
\end{enumerate}
This is the operational bridge from particle mechanics to the repository's
shared evaluation layer.

\section{PF Numeric Walkthrough}

Take a bootstrap PF with three particles at step \(k\). Assume the prior
weights are uniform,
\begin{equation}
    w_{k-1}^{(1)} = w_{k-1}^{(2)} = w_{k-1}^{(3)} = \frac{1}{3},
\end{equation}
and the observation likelihoods at the new measurement are
\begin{equation}
    p(z_k \mid x_k^{(1)}) = 0.50,\qquad
    p(z_k \mid x_k^{(2)}) = 0.30,\qquad
    p(z_k \mid x_k^{(3)}) = 0.20.
\end{equation}
The unnormalized weights are therefore
\begin{equation}
    \tilde{w}_k^{(1)} = 0.1667,\quad
    \tilde{w}_k^{(2)} = 0.1000,\quad
    \tilde{w}_k^{(3)} = 0.0667,
\end{equation}
with total mass \(0.3334\). After normalization,
\begin{equation}
    w_k^{(1)} = 0.50,\qquad
    w_k^{(2)} = 0.30,\qquad
    w_k^{(3)} = 0.20.
\end{equation}
If the particle states are
\begin{equation}
    x_k^{(1)} = 0.90,\qquad
    x_k^{(2)} = 1.10,\qquad
    x_k^{(3)} = 1.50,
\end{equation}
then the weighted state estimate is
\begin{equation}
    \hat{x}_k
    =
    0.50(0.90) + 0.30(1.10) + 0.20(1.50)
    =
    1.08.
\end{equation}
The effective sample size is
\begin{equation}
    N_{\text{eff}}
    =
    \frac{1}{0.50^2 + 0.30^2 + 0.20^2}
    \approx 2.63.
\end{equation}
Since \(2.63\) is above the usual resampling threshold of \(0.5 N_p = 1.5\),
this update would not resample. The point of the walkthrough is not that these
numbers are special; it is that the PF rung now has a fully numeric posterior
update, state estimate, and degeneracy diagnostic in the same style as IMM.

\section{RBPF As A Hybrid Sampled / Analytic Algorithm Family}

Rao-Blackwellized particle filtering is only justified when the latent state
splits into a sampled hard part and a conditionally tractable continuous part.
Write
\begin{equation}
    x_k = (r_k, s_k),
\end{equation}
where \(r_k\) is the sampled latent variable and \(s_k\) is the continuous
substate that can still be filtered analytically. The particle update samples
the hard part,
\begin{equation}
    r_k^{(i)} \sim p(r_k \mid r_{k-1}^{(i)}),
\end{equation}
and then runs a conditional Kalman-style update for the tractable substate,
\begin{align}
    \hat{s}_{k|k-1}^{(i)}
    &=
    F_k^{(r_i)} \hat{s}_{k-1|k-1}^{(i)} + b_k^{(r_i)},
    \\
    \hat{P}_{k|k-1}^{(i)}
    &=
    F_k^{(r_i)} \hat{P}_{k-1|k-1}^{(i)} F_k^{(r_i)\top} + Q_k^{(r_i)}.
\end{align}
The particle weight is then driven by the conditional innovation likelihood,
\begin{equation}
    \tilde{w}_k^{(i)}
    =
    w_{k-1}^{(i)}
    \mathcal{N}\!\big(\nu_k^{(i)}; 0, S_k^{(i)}\big),
\end{equation}
followed by the same normalization and optional resampling used by PF.

In the current 1D implementation, this split is no longer hypothetical. The
sampled variable is the discrete mode index
\begin{equation}
    r_k^{(i)} \in \{\text{coast},\text{accelerate},\text{brake},\text{maneuver}\},
\end{equation}
while the conditional continuous substate is the \(1\text{D}\) PVA block
\begin{equation}
    s_k^{(i)} = \big(p_k^{(i)}, v_k^{(i)}, a_k^{(i)}\big)^\top.
\end{equation}
The mode transition matrix in \texttt{rbpf\_models\_1d.py} samples the discrete
hypothesis, and \texttt{kalman\_predict\_update()} in \texttt{rbpf.py}
performs the conditional analytic update for each particle.

RBPF is the right rung only when the repo can point to a genuine split of this
form. If the state is not naturally decomposable into \((r_k, s_k)\), then an
RBPF claim is just a more complicated PF claim, not a justified hybrid method.

\section{RBPF Process Summary}

The intended RBPF recursion is:
\begin{enumerate}[leftmargin=1.5em]
    \item sample the hard latent variable \(r_k^{(i)}\) for each particle,
    \item condition on \(r_k^{(i)}\) and run an analytic predict/update step
    for the tractable substate \(s_k^{(i)}\),
    \item use the conditional innovation likelihood to update particle
    weights,
    \item normalize and optionally resample exactly as in PF,
    \item combine the conditional state estimates into a weighted global state
    summary,
    \item aggregate particle-level evidence into class or mode evidence for the
    shared posterior surface.
\end{enumerate}
So RBPF is not a different outer loop from PF. It is PF with an internal
analytic subfilter that reduces variance when a real sampled/analytic split is
available.

\section{RBPF Numeric Walkthrough}

Take a two-particle RBPF for an unknown maneuver-onset witness. Suppose the
sampled latent variable is the onset index and the conditional continuous state
is the usual \((p, v, a)\) block. Let the two sampled onset hypotheses have
prior weights
\begin{equation}
    w_{k-1}^{(1)} = 0.60,\qquad
    w_{k-1}^{(2)} = 0.40.
\end{equation}
After the conditional Kalman updates, suppose the innovation likelihoods are
\begin{equation}
    \mathcal{N}(\nu_k^{(1)};0,S_k^{(1)}) = 0.42,\qquad
    \mathcal{N}(\nu_k^{(2)};0,S_k^{(2)}) = 0.14.
\end{equation}
The unnormalized particle weights become
\begin{equation}
    \tilde{w}_k^{(1)} = 0.252,\qquad
    \tilde{w}_k^{(2)} = 0.056,
\end{equation}
so after normalization
\begin{equation}
    w_k^{(1)} \approx 0.818,\qquad
    w_k^{(2)} \approx 0.182.
\end{equation}
If the conditional continuous-state means are
\begin{align}
    \hat{s}_{k|k}^{(1)} &= (10.0,\ 1.0,\ 0.0), \\
    \hat{s}_{k|k}^{(2)} &= (9.2,\ 0.6,\ -0.2),
\end{align}
then the RBPF combined state estimate is
\begin{align}
    \hat{s}_{k|k}
    &=
    0.818(10.0,\ 1.0,\ 0.0)
    +
    0.182(9.2,\ 0.6,\ -0.2)
    \\
    &\approx
    (9.855,\ 0.927,\ -0.036).
\end{align}
The effective sample size is
\begin{equation}
    N_{\text{eff}}
    =
    \frac{1}{0.818^2 + 0.182^2}
    \approx 1.42.
\end{equation}
That is the numeric point of RBPF: the hard latent onset hypothesis is carried
by the particles, while the continuous kinematics remain analytically filtered
inside each particle. If a future witness does not really split that way, RBPF
is not the right rung.

\section{Why IMM Is Stronger Than The Transition-Matrix Rung}

The transition-matrix accumulator already updates
\begin{equation}
p_k(c)
\propto
p(y_k \mid c)\sum_j T_{jc}p_{k-1}(j),
\end{equation}
so it handles switching at the label level. IMM is stronger because it also
mixes mode-conditioned state estimates and covariances before the next Kalman
update. In other words:
\begin{itemize}[leftmargin=1.5em]
    \item transition-matrix accumulation mixes \emph{class probability mass},
    \item IMM mixes \emph{state distributions} and then scores innovations per
    mode.
\end{itemize}
That is the real upgrade claim. IMM is not just ``transition matrix plus more
math.'' It is the first rung where switching structure changes the latent-state
estimate itself.

\section{Why IMM, PF, and RBPF Remain Decision-Gated}

The current rule is not merely verbal. The implemented gate logic is based on
measured gains from simpler rungs. For IMM-like switching logic, the current
decision report computes quantities such as
\begin{align}
    \Delta_{\text{post-switch}}^{\text{TM-static}}
    &= A_{\text{post-switch}}^{\text{transition matrix}}
    - A_{\text{post-switch}}^{\text{static accumulator}}, \\
    \Delta_{\text{post-switch}}^{\text{IMM-TM}}
    &= A_{\text{post-switch}}^{\text{IMM}}
    - A_{\text{post-switch}}^{\text{transition matrix}}, \\
    \Delta_{\text{post-switch}}^{\text{TM-kalman}}
    &= A_{\text{post-switch}}^{\text{transition matrix}}
    - A_{\text{post-switch}}^{\text{switching Kalman bank}}.
\end{align}
The repo's present interpretation is:
\begin{itemize}[leftmargin=1.5em]
    \item if \(\Delta_{\text{post-switch}}^{\text{TM-static}} > 0\), switching
    structure matters at least at the label level;
    \item if \(\Delta_{\text{post-switch}}^{\text{IMM-TM}} > 0\) materially and
    consistently, then full state mixing may be justified rather than merely
    finite-state transition accumulation;
    \item if the switching Kalman bank still loses to the transition-matrix
    rung, then the repo does not yet have evidence that the simpler switching
    ladder is exhausted.
\end{itemize}
That is why IMM remains evidence-gated even though the repo now has an IMM
proof surface. Existence of an implementation is not the same thing as a claim
that the implementation is necessary.

For particle filtering, the current decision surface is driven by the absence of
a demonstrated nonlinear or non-Gaussian benchmark and by the fact that the
strongest hard case remains sensing-limited. The implemented evidence rows in
\texttt{advanced\_filter\_decision.py} are therefore evaluating a logic of the
form
\begin{align}
    \text{PF justified}
    &\Longrightarrow
    \text{nonlinear benchmark exists}
    \land
    \text{robust Kalman still fails}
    \notag \\
    &\qquad \land
    \text{failure is not primarily sensing-limited}.
\end{align}
The artifact
\path{artifacts/advanced_filter_decision_v1/advanced_filter_decision_numeric_walkthrough.md}
now expands one real decision pass numerically. It substitutes the measured
transition gains, identifiability gaps, velocity-aided improvement, and best
Kalman outlier accuracy into the gate interpretation so the current
``defer IMM / defer PF'' result is justified by actual evidence values rather
than only a prose rule.

For RBPF, the required latent structure is stricter still. The intended
decision criterion is:
\begin{equation}
    \text{RBPF justified}
    \Longrightarrow
    x_t = (u_t, v_t),
\end{equation}
with \(u_t\) representing a sampled nonlinear or discrete latent structure and
\(v_t\) representing a conditionally linear-Gaussian substate that can still be
filtered analytically.

\section{Interpretation Of The Current Gate}

The current rule is therefore:
\begin{itemize}[leftmargin=1.5em]
    \item IMM is deferred until switching evidence clearly exceeds what the
    current transition-aware ladder handles.
    \item PF is deferred until nonlinear or non-Gaussian behavior defeats the
    current recursive methods for reasons other than sensing limits.
    \item RBPF is deferred until there is a real sampled-latent plus
    conditionally tractable continuous-state split.
\end{itemize}

That is why the advanced-filter decision reports are architecture artifacts, not
mere TODO notes. They encode the proof obligation for adding more complexity.
