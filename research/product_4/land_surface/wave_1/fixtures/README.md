# Fixture Boundary

No source trajectory rows or coordinate arrays are committed in this public research tranche.

A six-record ReV-StED local witness was built from immutable source records and passed the local
structural validator. Its concrete redistribution license remains unresolved, so the source
extract, source-native state asset, analysis state asset, and combined fixture stay outside the
repository.

statements. highD data remains subject to provider restrictions.

The next portable LAND fixture should be a bounded complete TGSIM track set with exact retrieval
definition, source snapshot identity, retained bytes, SHA-256, actual-row schema inspection, and
authoritative COMMON-FRONT validation.
